# Humanoid Quest Book - Fall 2026 (F26)

## The Great Objective: Fully Assembled Humanoid

Assemble the complete humanoid (2 arms + 2 legs) as the primary objective of the term, with finalized arm/leg mechanical design and a testing setup to support it. In parallel, finish the electrical system with a manufactured custom PCB, get reliable system-wide interfacing and IMU integration for locomotion on firmware, make progress on locomotion and manipulation policies with RL sim2real work started, and power up the 22DOF hand as a secondary goal.

## Term Objectives Summary

1. **General & Planning**
	- Whole humanoid fully assembled (2 arms + 2 legs)
	- Arm and leg mechanical design finalized, testing setup built

2. **Software**
	- Locomotion policy progress
	- Manipulation progress
	- RL sim2real deployment started
	- Successful autonomous task demo deployed
	- Leader arm built for teleop data collection

3. **Embedded / Firmware**
	- Reliable interfacing across the system (MIT control mode + CAN FD)
	- IMU integration for locomotion
	- 22DOF hand powered and functional
	- Full bringup on hand, legs, and full body (where mechanically possible)
	- Telemetry dashboard

4. **Mechanical**
	- Arm and leg design finalized and built for testing

5. **Power Systems / Electrical**
	- Full electrical system complete
	- PCB designed and manufactured
